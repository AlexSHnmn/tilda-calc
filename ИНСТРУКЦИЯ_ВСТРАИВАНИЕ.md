# 📋 Как встроить настройки в код и сохранить их при публикации

## Проблема, которую мы решили

Калькулятор хранил настройки в `localStorage` браузера. Когда вы редактируете страницу в Tilda (в preview-режиме на одном поддомене) и публикуете (на другом домене), localStorage разный — поэтому настройки "сбивались".

**Теперь:** настройки встраиваются **прямо в HTML-код**, так что они живут везде и всегда.

---

## Пошаговая инструкция

### Шаг 1: Внесите все нужные изменения в Настройках

1. На сайте Tilda откройте калькулятор
2. Нажмите кнопку ⚙ (Настройки) 
3. Введите пароль: `VDMK26`
4. Отредактируйте нужные значения:
   - **Тарифы** — цены на услуги
   - **Email** — способ отправки расчётов, адреса почты
   - **Тексты** — все тексты на странице
   - **Каталог** — цены товаров, скрытые товары

### Шаг 2: Сохраните все изменения

Нажмите **💾 Сохранить** в каждом разделе, который вы редактировали.

### Шаг 3: Встройте настройки в код

В панели Настроек → **Email** найдите новую кнопку:
```
📋 Встроить настройки в код
```

Нажмите её → появится сообщение **"✓ Код скопирован"**.

В буфер обмена скопирована строка вроде:
```javascript
const EMBEDDED_SETTINGS = {"svc":{"liq":5.2,...},"txt":{...},"email":{...},...};
```

### Шаг 4: Вставьте код в HTML Tilda

1. В Tilda откройте редактор HTML-блока калькулятора
2. Найдите строку:
   ```javascript
   const EMBEDDED_SETTINGS = null;
   ```
   (примерно на строке 1297)

3. **Полностью замените эту строку** на скопированный код

Было:
```javascript
const EMBEDDED_SETTINGS = null;
```

Стало (вставляем из буфера обмена):
```javascript
const EMBEDDED_SETTINGS = {"svc":{"liq":5.2,...},...};
```

### Шаг 5: Сохраните и опубликуйте

1. Сохраните изменения в HTML-блоке
2. Опубликуйте страницу Tilda

**Готово!** Теперь все ваши настройки встроены прямо в HTML и будут везде одинаковые.

---

## Что происходит при загрузке калькулятора

При открытии страницы калькулятор проверяет в таком порядке:

1. **localStorage** — если вы недавно меняли что-то на сайте (имеет приоритет)
2. **EMBEDDED_SETTINGS** — встроённые в код настройки (появляются если нет localStorage)
3. **Дефолты** — если ничего не найдено

---

## Чек-лист перед публикацией

- ✓ Все нужные изменения внесены в Настройки
- ✓ Все изменения **сохранены** (нажали 💾)
- ✓ Нажали «Встроить в код» и скопировали JS-код
- ✓ В HTML Tilda заменили `const EMBEDDED_SETTINGS = null;` на скопированный код
- ✓ Опубликовали страницу

## Если что-то пошло не так

### Вариант 1: Забыли скопировать код
Просто откройте калькулятор, войдите в Настройки, нажмите «Встроить в код» снова.

### Вариант 2: Не скопировалось в буфер обмена
Код должен быть виден в окне с ошибкой. Скопируйте его вручную из консоли браузера:
1. Откройте DevTools (F12)
2. Найдите код в диалоговом окне ошибки
3. Скопируйте вручную

### Вариант 3: Настройки всё равно сбиваются
Убедитесь что вы **полностью заменили** строку `const EMBEDDED_SETTINGS = null;` на новый код.

---

## Разница между localStorage и EMBEDDED_SETTINGS

| | localStorage | EMBEDDED_SETTINGS |
|---|---|---|
| **Где хранится** | В браузере | В HTML-коде |
| **Видно ли в preview Tilda** | Нет (другой домен) | Да (часть кода) |
| **Видно ли на сайте** | Да | Да |
| **Обновляется при публикации** | Нет | Нет (нужно вручную встраивать) |
| **Безопасно ли** | Да, только локально | Нет (видно в исходнике) |

**Вывод:** используйте оба! localStorage для оперативных изменений, EMBEDDED_SETTINGS чтобы настройки "переезжали" с кодом.
