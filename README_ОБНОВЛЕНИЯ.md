**Было:**
1. Меняешь настройки → нажимаешь "Сохранить"

**Теперь:**
1. Меняешь настройки → нажимаешь "Сохранить"
2. ✨ Всё автоматически опубликовано! (готово через 30 сек)

## 🎯 Как начать (5 минут)

### Один раз: Ввести GitHub токен

1. Откройте https://github.com/settings/personal-access-tokens/new
2. Выберите репозиторий `tilda-calc`
3. Дайте право **Contents: Read and write**
4. **Generate token** и скопируйте (выглядит как `ghp_...`)
5. На сайте Tilda → Настройки → вкладка **⚡ Публикация**
6. Вставьте токен → нажмите **Сохранить токен**
7. Нажмите **Проверить токен** → должно показать ✓

**Готово!** Больше ничего делать не нужно.

### Каждый день: Просто меняешь и сохраняешь

```
Меняешь число  →  Нажимаешь "Сохранить"  →  ✓ Опубликовано!
                                              (через 30 сек)
```

## 🔧 Технические детали

### Что встроилось в код

- **Переменная `EMBEDDED_SETTINGS`** — ваши настройки живут прямо в HTML-коде
- **Панель "⚡ Публикация"** — для ввода GitHub токена
- **Автоматическое обновление** — при нажатии "Сохранить" отправляется на GitHub API

### Как это работает

```
Вы нажимаете "Сохранить"
         ↓
Браузер собирает все настройки из localStorage
         ↓
Отправляет на GitHub API
         ↓
GitHub обновляет файл calculator-unified.html
         ↓
GitHub Pages публикует (20-40 сек)
         ↓
Сайт на Tilda обновляется
         ↓
✓ Готово!
```

## 🆘 Если что-то не работает

### Проверка 1: Токен
1. Откройте Настройки → вкладка **⚡ Публикация**
2. Нажмите **🔍 Проверить токен**
3. Если показывает **✓** — всё в порядке
4. Если **✗** — токен неправильный или устаревший → создайте новый

### Проверка 2: Обновление
1. Измените что-нибудь в тарифах (число или текст)
2. Нажмите **Сохранить**
3. Должно показать **✓ Опубликовано**
4. Через 30 сек откройте сайт в новом браузере → видны ли изменения?

### Проверка 3: GitHub
1. Откройте https://github.com/alexshnmn/tilda-calc/commits/main
2. Найдите коммит "Обновление настроек калькулятора"
3. Он должен содержать обновлённые значения в `EMBEDDED_SETTINGS`

---

## 💡 Советы

- **Токен** хранится только в вашем браузере, не встраивается в код
- **Разные компьютеры** — токен нужно вводить на каждом браузере отдельно
- **Если забыли токен** — создайте новый на GitHub (старый при этом перестанет работать)
- **Безопасность** — не делитесь компьютером с другими, токен полностью открывает доступ к файлу
