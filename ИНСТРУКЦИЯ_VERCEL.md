# 🚀 Полная автоматизация: Backend на Vercel

Теперь настройки публикуются **полностью автоматически** без ввода токена в браузер каждый раз!

---

## 🎯 Как это работает

```
Менеджер меняет настройки на Tilda
    ↓
Нажимает "Сохранить"
    ↓
Браузер отправляет данные на Vercel API
    ↓
Vercel получает запрос, использует свой GitHub токен
    ↓
Обновляет файл на GitHub
    ↓
GitHub Pages публикует (~30 сек)
    ↓
Сайт обновлён! 🎉
```

**Токен хранится безопасно в переменных Vercel, не в коде!**

## ⚙️ Одноразовая настройка (10 минут)

### Шаг 1: Создайте новый GitHub токен

⚠️ **ВАЖНО**: Старый токен скомпрометирован! Создайте новый:

1. https://github.com/settings/personal-access-tokens
2. Нажмите **Generate new token (classic)** (или просто **New**)
3. Заполните:
   - **Token name**: `tilda-calc-vercel`
   - **Expiration**: `No expiration` (или 90 дней)
   - **Scopes**: отметьте только **repo** (полный доступ)
4. **Generate token** и **скопируйте** (больше не покажется!)

### Шаг 2: Подключите Vercel

1. Откройте https://vercel.com
2. Нажмите **Sign Up** (или **Sign In** если есть аккаунт)
3. Выберите **GitHub** для регистрации
4. Разрешите доступ к вашим репозиториям

### Шаг 3: Импортируйте проект

1. На Vercel нажмите **Add New** → **Project**
2. Найдите репозиторий `tilda-calc`
3. Нажмите **Import**
4. В разделе **Environment Variables** добавьте:
   ```
   GITHUB_TOKEN = [ВСТАВЬТЕ ТОКЕН ИЗ ШАГА 1]
   GITHUB_REPO = AlexSHnmn/tilda-calc
   GITHUB_FILE = calculator-unified.html
   GITHUB_BRANCH = main
   ```
5. Нажмите **Deploy**

### Шаг 4: Готово! 🎉

Vercel автоматически развернёт backend на https://tilda-calc.vercel.app

Проверьте: https://tilda-calc.vercel.app/api/publish (должен показать ошибку 405 - это нормально)

## 📚 Как использовать

### На Tilda

**Менеджерам ничего не нужно делать особого!**

1. Откройте калькулятор на сайте Tilda
2. Нажмите ⚙ **Настройки** → введите пароль
3. **Вкладка "⚡ Публикация"** - здесь больше **никакой ввод токена не нужен**!
4. Меняйте что угодно → **Сохранить** → готово!

Настройки автоматически публикуются на GitHub Pages.

### Статус публикации

В панели "⚡ Публикация" будет видно:
- 🟡 **Публикую на GitHub...** — идёт отправка
- ✓ **Опубликовано** — готово (обновление на сайте через 30 сек)
- ✗ **Ошибка** — что-то не так

## 🔒 Безопасность

✅ **Токен защищен:**
- Хранится в **переменных окружения Vercel** (не в коде)
- **Не видно** в браузере или в исходнике HTML
- **Не передаётся** клиентом (только сервер его использует)
- Каждый менеджер может работать с одним токеном

✅ **Репозиторий защищён:**
- Только обновление файла `calculator-unified.html`
- Прямой доступ к другим файлам невозможен

## 🚨 Если что-то не работает

### Проверка 1: Vercel развёрнут?

Откройте https://tilda-calc.vercel.app/api/publish в браузере.
Должно показать: `{"error":"Method not allowed"}`

Если **404** → Vercel не развёрнут. Попробуйте ещё раз загрузить с шага 3.

### Проверка 2: GitHub токен правильный?

В Vercel откройте проект → **Settings** → **Environment Variables**

Убедитесь:
- `GITHUB_TOKEN` заполнен (начинается с `ghp_`)
- `GITHUB_REPO` = `AlexSHnmn/tilda-calc`

### Проверка 3: Тест публикации

1. На Tilda откройте калькулятор
2. Зайдите в Настройки → **Тарифы**
3. Измените одно число
4. Нажмите **Сохранить**
5. Смотрите статус в панели "⚡ Публикация"

Если ошибка → откройте консоль браузера (F12) и посмотрите что именно пишет.

## 📞 Проблемы и решения

| Проблема | Решение |
|----------|---------|
| **Vercel says "Method not allowed"** | Нормально! API работает, но ожидает POST. |
| **"GitHub токен не конфигурирован"** | Добавьте `GITHUB_TOKEN` в Environment Variables Vercel |
| **"EMBEDDED_SETTINGS не найдена"** | Файл на GitHub поменялся. Пушните актуальный |
| **Публикация очень медленная** | GitHub Pages кэширует. Обновление может занять 1 минуту |
| **Токен скомпрометирован** | Удалите старый → создайте новый → обновите в Vercel |

## 🔄 Какие настройки публикуются

Все:
- ✅ Тарифы (все цены)
- ✅ Email (способ отправки, адреса, тексты)
- ✅ Тексты (все надписи на странице)
- ✅ Товары (цены по категориям, скрытые товары)
- ✅ Кастомные товары (добавленные менеджерами)
