# Email Integration Setup для Калькулятора СТМ

## Обзор
Калькулятор теперь может отправлять расчёты на почту клиента и копию менеджеру. Доступны 3 способа интеграции.

## Способ 1: Formspree (Рекомендуется для быстрого старта)

### Шаги:
1. Перейдите на https://formspree.io
2. Зарегистрируйтесь или войдите
3. Создайте новую форму
4. Получите Form ID (выглядит как `abc123def456`)
5. В администраторской панели калькулятора:
   - Выберите вкладку "Email"
   - Способ отправки: "Formspree"
   - API ключ: вставьте Form ID
   - Email менеджера: ваша рабочая почта
   - Сохраните

**Преимущества:**
- Не требует своего бэкенда
- Автоматически обрабатывает письма
- Бесплатный план с ограничениями

**Ограничения:**
- Бесплатный план: 50 писем в месяц

---

## Способ 2: EmailJS (Для большего объёма писем)

### Шаги:
1. Перейдите на https://www.emailjs.com
2. Зарегистрируйтесь
3. Создайте сервис (например, Gmail)
4. Создайте шаблон письма
5. Получите Public Key
6. Добавьте скрипт EmailJS в HTML:

```html
<script type="text/javascript" src="https://cdn.jsdelivr.net/npm/@emailjs/browser@3/dist/index.min.js"></script>
<script type="text/javascript">
  emailjs.init("ВАШ_PUBLIC_KEY");
</script>
```

7. В администраторской панели:
   - Способ отправки: "EmailJS"
   - API ключ: ваш Public Key
   - Email менеджера: ваша рабочая почта

**Преимущества:**
- Больше писем в бесплатном плане (200/месяц)
- Поддерживает HTML письма
- Большая гибкость

**Требуется:**
- Настройка Email Service (Gmail, Outlook, и т.д.)

---

## Способ 3: Свой бэкенд

### Для разработчиков
Если у вас есть свой сервер, создайте API endpoint:

**Endpoint:** `POST /api/send-calculation`

**Ожидаемые параметры:**
```json
{
  "clientEmail": "client@example.com",
  "managerEmail": "manager@company.com",
  "clientName": "Иван Сидоров",
  "clientPhone": "+7 999 999 99 99",
  "message": "Полный текст расчёта..."
}
```

**Требуемые действия:**
1. Отправить письмо на `clientEmail` с расчётом
2. Отправить письмо на `managerEmail` с контактами клиента
3. Вернуть 200 OK

**В калькуляторе:**
- Способ отправки: "Свой бэкенд"
- API ключ: URL вашего endpoint (например, `https://api.company.com/api/send-calculation`)
- Email менеджера: ваша рабочая почта

**Пример на Node.js/Express:**
```javascript
const nodemailer = require('nodemailer');

app.post('/api/send-calculation', async (req, res) => {
  const { clientEmail, managerEmail, clientName, clientPhone, message } = req.body;
  
  try {
    // Отправить клиенту
    await sendEmail(clientEmail, `Ваш расчёт`, message);
    
    // Отправить менеджеру
    const managerMsg = `Новая заявка от ${clientName}\nТелефон: ${clientPhone}\n\n${message}`;
    await sendEmail(managerEmail, `Новая расчёт-заявка`, managerMsg);
    
    res.json({ success: true });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});
```

## Администраторские настройки

В панели настроек калькулятора (пароль: VDMK26):
1. Перейдите на вкладку "Email"
2. Укажите:
   - **Email менеджера** - основная рабочая почта
   - **Способ отправки** - выбирите один из способов
   - **API ключ/URL** - ключ или адрес для выбранного способа
   - **Текст в письме** - дополнительный текст, который будет отправляться клиенту

---

## Форма для клиента

После расчёта появляется блок "Получить расчёт на почту" где клиент указывает:
- Имя
- Телефон
- Email
- Галочка согласия на обработку данных (обязательно по закону РФ)

Нажав "Сохранить расчет", система отправляет:
- **Клиенту:** подробный расчёт с инструкциями
- **Менеджеру:** расчёт + контакты клиента

## Проверка работы

1. Откройте калькулятор в браузере
2. Выберите продукт и параметры
3. Заполните форму email (внизу страницы)
4. Нажмите "Сохранить расчет"
5. Проверьте почту менеджера и клиента

## Troubleshooting

| Проблема | Решение |
|---------|---------|
| Письма не приходят | Проверьте email менеджера в настройках. Проверьте SPAM папку |
| Ошибка "Email не настроен" | Заполните email менеджера в админ-панели на вкладке Email |
| Ошибка при отправке | Проверьте API ключ и способ отправки. Смотрите консоль браузера (F12) |
| Письма идут на Formspree | Убедитесь что вы используете Form ID, а не весь URL |

---

## Безопасность

- Данные клиента НЕ хранятся в браузере (только в памяти на время отправки)
- Все передачи через HTTPS (если сайт на HTTPS)
- Персональные данные отправляются только при явном согласии клиента

## Поддержка и вопросы

Если у вас возникают проблемы:
1. Проверьте консоль браузера (F12 → Console) для ошибок
2. Убедитесь что email менеджера указан в настройках
3. Проверьте выбранный способ отправки и API ключ
