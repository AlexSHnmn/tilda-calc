# ⚡ Автоматическая публикация настроек на GitHub Pages

Теперь все ваши изменения в панели администратора **автоматически публикуются** без ручного встраивания кода в Tilda!

---

## Как это работает

1. **Вы меняете настройки** в панели администратора (тарифы, email, тексты, товары)
2. **Нажимаете "💾 Сохранить"**
3. **Браузер автоматически** отправляет обновления на GitHub через API
4. **GitHub Pages публикует** новую версию сайта (~30 секунд)
5. **Готово!** На вашем сайте уже действуют новые настройки

---

## Первая настройка (5 минут)

### Шаг 1: Получить GitHub Personal Access Token

1. Откройте https://github.com/settings/personal-access-tokens/new
2. В разделе **Resource owner** — выберите `alexshnmn` (ваш аккаунт)
3. В разделе **Repository access** — выберите:
   - **Only select repositories** → `tilda-calc`
4. В разделе **Permissions** — нужно дать право:
   - **Contents** → `Read and write`
5. **Generate token**
6. ⚠️ **Скопируйте токен!** Он показывается только один раз

Токен выглядит как: `ghp_...` (длинная строка)

### Шаг 2: Введите токен в калькулятор

1. На сайте Tilda откройте калькулятор
2. Нажмите ⚙ **Настройки**
3. Введите пароль: `VDMK26`
4. Нажмите на вкладку **⚡ Публикация**
5. В поле **GitHub Personal Access Token** вставьте токен
6. Нажмите **💾 Сохранить токен**
7. Нажмите **🔍 Проверить токен** → должно показать ✓

**Готово!** Теперь используйте калькулятор как обычно, все изменения будут автоматически публиковаться.

## Проверить что всё работает

### Быстрая проверка

1. **Откройте панель** → вкладка **⚡ Публикация**
2. Нажмите **🔍 Проверить токен**
3. Должно показать: **✓ Токен рабочий, репозиторий доступен**

Если показывает ошибку — токен устаревший или неправильно введён.

### Проверка публикации

1. **Откройте панель** → вкладка **Тарифы**
2. **Измените любое число** (например, фасовку с 5.2 на 5.3)
3. **Нажмите Сохранить**
4. **Посмотрите статус** → должно показать **✓ Опубликовано на GitHub Pages**
5. **Через 30 секунд обновите сайт** в браузере (F5)
6. **Проверьте что число изменилось** ✓

## Часто задаваемые вопросы

### ❓ Что будет, если я выключу браузер во время публикации?

Ничего страшного! GitHub API запрос отправился, публикация произойдёт как обычно.

### ❓ Что если забыл токен?

Получите новый:
1. https://github.com/settings/personal-access-tokens/new
2. Выберите `tilda-calc` репозиторий
3. Дайте права на **Contents** → `Read and write`
4. Generate и вставьте новый токен в калькулятор

Старый токен при этом перестанет работать.

### ❓ Как токен хранится? Это безопасно?

- Токен хранится **только в localStorage** вашего браузера
- **Не встраивается в HTML** и не видно на сайте
- **Не отправляется** никому кроме GitHub API
- Каждый администратор может ввести свой токен

### ❓ Почему медленно обновляется сайт?

GitHub Pages кэширует содержимое. Обновление занимает:
- 30-40 сек обычно
- До 2 минут если был большой трафик

Если очень медленно — очистите кэш браузера (Ctrl+Shift+Delete).

### ❓ Работает ли с разных компьютеров?

**Нет!** Токен хранится в localStorage **конкретного браузера**. Если вы:
- Откроете калькулятор на другом компьютере — нужно ввести токен снова
- Очистите cookie/кэш браузера — нужно ввести токен снова
- Откроете в другом браузере — нужно ввести токен снова

### ❓ Что если кто-то украдёт мой GitHub токен?

Он получит возможность только обновлять файл `calculator-unified.html`. Чтобы защитить:
1. Используйте браузер только вы (не делитесь компьютером)
2. Закрывайте браузер после работы
3. Если подозреваете утечку — удалите токен на GitHub и создайте новый

### ❓ Могу ли я отключить автопубликацию?

Просто не вводите токен! Тогда:
- Панель будет работать как раньше
- Нужно будет вручную встраивать код в Tilda (читайте `ИНСТРУКЦИЯ_ВСТРАИВАНИЕ.md`)

## Техническая информация

### Что происходит при сохранении

```
Браузер (localStorage)
    ↓
⬆ Отправляет JSON через GitHub API
    ↓
GitHub (главный файл HTML)
    ↓ (обновляет строку EMBEDDED_SETTINGS)
    ↓
GitHub Pages CDN
    ↓ (публикует обновления)
    ↓
Ваш сайт на Tilda (кэш обновляется)
    ↓ (~30 сек)
    ↓
Посетители видят новые настройки 🎉
```

### Что обновляется в файле

Строка (примерно 1298):
```javascript
// Было:
const EMBEDDED_SETTINGS = null;

// Стало:
const EMBEDDED_SETTINGS = {"svc":{...},"txt":{...},"email":{...},...};
```

GitHub коммит содержит полный JSON всех настроек.
